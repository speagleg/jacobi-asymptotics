**Goal.** Prove Theorem RH_p for 0 < p < 1 and s > 1: for σ_{p,s} = Σ k^{−s}δ_{k^{−p}},

  n^p b_n = c(p)(1 + O(1/n)),  a_n/(2b_n) = 1 + O(1/n).

With RH₁(r) and RH_p (p > 1) this gives the pointwise law for **all** pure powers with power weights.

**Baseline (NUMERICAL, scratch probe; to be committed as checks/check_plt1_phase0.py).** With exact atoms k ≤ K and a
log-panel Euler–Maclaurin tail (K-stability ≤ 10⁻¹⁰ for n ≤ 200):
- n(n^p b_n/c(p) − 1) → −(s − 1)/2, for (p, s) = (0.5, 2), (0.5, 3), (0.75, 2) (values −0.504, −1.007, −0.500 at
  n = 400);
- n(a_n/(2b_n) − 1) → ≈ 0.25 … 0.37.

The same d₁ = −(s − 1)/2 appears for p > 1 (RH_px §5).

**Obstruction (RH_px Lemma 1.1).** For p < 1, t = Nz^{−1/p} leaves the Stirling sector for |arg z| > πp.
- D's continuation picks up the exponential factors (1 − e^{±2πit})^{∓1}, and for p < ½ phantom poles on arg z = ±2πp.
- On (−∞, 0) the jump log D₊/D₋ grows like N|x|^{−1/p}, which is non-integrable at 0 for p < 1. So the Binet-cut scalar
  B does not exist.

**Design.**
1. **Sector-restricted D, seam scalar X.** Use D only in the inner sector S_in = {|arg z| < θ_s}, with θ_s := πp/2.
   There t stays in the Stirling sector and |e^{∓2πit}| ≤ exp(−2π sin(θ_s/p)|t|).
   - On the seam rays arg z = ±θ_s, log D = O(|z|^{1/p}/N) near 0 (Binet), which is integrable.
   - Define X as the Cauchy integral over the seams of log D, normalized at a point and with RH_px Lemma 3.5-type
     monodromy bookkeeping at ∞. Put F := D·K·e^X in S_in and F := K·e^X outside.
   - Then F is continuous, hence analytic, across the seams. It cancels T's real-axis jumps as D did, and it needs no B.
2. **Hard edge by the comparison method.** Plan 14 §1: Bessel parametrix with W̃ := D_w; lip mismatch; Lemma UR;
   Theorem C; Proposition D.
   - No continuation of w₀ beyond S_in is needed, since D_w is analytic off the band.
   - The lips and Σ^△ lie inside S_in.
   - Here the lip mismatch is O(|z|^ν) (Hölder h_N; there is no log), so ‖v − ṽ‖_∞ = O(N^{−2ν}).
3. **Everything else verbatim from RH_px:** μ* (G2, all p > 0), Lemma 3.5 normalization, Airy at 4c, top end.
   - Check that every RH_px step that used the slit plane uses only S_in, or the far region where F = K e^X.
