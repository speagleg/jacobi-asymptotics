### 2.2 Steps (a) and (b)

(a) The rank-one update, the matrix determinant lemma and vᵀH_m^{−1}v = K_{m−1}(x₀, x₀) are correct, and so is
b_n² = D_{n+1}D_{n−1}/D_n². Parseval for 1_{x₀}: ⟨1_{x₀}, P_j⟩ = w₀P_j(x₀) and ‖1_{x₀}‖² = w₀, so Σ_jP_j(x₀)² = 1/w₀, given
completeness. Completeness needs only Weierstrass, not the L²-density of C(supp σ): x₀ = k₀^{−p} is an **isolated** point of

is within ησ(ℝ)^{1/2} in L²(σ). F4 is about citing this.

(b) Write A := x₀ − α_j and the denominator d(ρ) = A − b_{j+1}ρ. With α_j = 2b_j(1 + β_j) and b_{j+1} = b_j(1 + γ_j),
d(ρ)/x₀ = 1 − u_j(1 + β_j)/2 − u_j(1 + γ_j)ρ/4 ≥ 1 − 3u_j/4 − O(u_j/j) on [0, 1]. This is the relative form; the O-term carries
the factor u_j. From it:
- Φ_j is increasing on [0, 1];
- Φ_j(1) ≤ (u_j/(4 − 3u_j))(1 + O(1/j));
- Φ_j′ = b_jb_{j+1}/d² ≤ (u_j/(4 − 3u_j))²(1 + O(1/j)).

All as claimed. With u_j ≤ 1 − η/2, u/(4 − 3u) ≤ (1 − η/2)/(1 + 3η/2) < 1. Also u_j = u_n(n/j)^p(1 + O(1/n)) for j ≥ n − 1, and
this tends to 0, so the bounds improve along the tail.

The fixed point of (ρ_j)_{j≥n−2} ↦ (Φ_{j+1}(ρ_{j+1})) on ([0, 1]^ℕ, sup) is a solution of the recurrence. It decays
geometrically, so it is in ℓ². The Casoratian W = b_j(P_jŶ_{j−1} − P_{j−1}Ŷ_j) is constant, and |W| ≤ b_j(|P_j||Ŷ_{j−1}| +

### 2.3 Step (c)

The recursion e_{j−1} = θ_je_j + D_j is correct (σ_j = Φ_j(σ_j), mean value theorem).

**"Contraction gives e_j = O(1/j)"** (F10, INFO). Iterating gives e_{j−1} = Σ_{i≥j}D_iΠ_{l=j}^{i−1}θ_l + (Π_{l=j}^{J}θ_l)e_J. The a
priori bound on e_J is only |e_J| ≤ 1/σ_J ≍ J^p/k₀^p, which grows polynomially. The product decays geometrically (indeed
θ_l ≤ Cu_l² → 0), so the last term vanishes as J → ∞. One sentence should say this.

**F2 (MINOR): uniformity as u → 0.** The file writes "Δu_j = u_jγ_j + O(j⁻²) = −pu_j/j + O(j^{−1−ε})" and then multiplies by
∂_u log S = 1/(u√(1 − u)) ~ 1/u. With *absolute* error terms this gives O(1/(u_jj²)) and O(j^{−1−ε}/u_j), which are not
uniform as u_j → 0 (far nodes, k₀ fixed, n → ∞). The fix is exact and short:
- Δu_j = u_{j−1}γ_{j−1};
- so Δlog u_j = log(1 + γ_{j−1}) = −p/j + O(j^{−1−ε});
- and Δ²log u_j = O(|Δγ| + j⁻²) = O(j^{−1−ε}).

These need no division by u.

**F3 (MINOR): the form of log σ_j.** "log σ_j = log u_j + h(u_j) + O(|β_j| + |γ_j|)" does not by itself give ΔD_j = O(j^{−1−ε}):
an arbitrary O(1/j) sequence can have first differences of order 1/j. What is true, and what the proof needs, is an exact
formula. Solving the frozen quadratic divided by x₀,

  σ_j = (u_j/2)/(A_j + √(A_j² − u_j²(1 + γ_j)/4)),   A_j := 1 − u_j(1 + β_j)/2,

so log σ_j = log u_j + h(u_j, β_j, γ_j), with h(u, β, γ) := −log(2A + 2√(A² − u²(1 + γ)/4)). This h is real-analytic, with bounded
derivatives on u ∈ [0, 1 − η/2], |β|, |γ| ≤ δ₀; the discriminant at β = γ = 0 is 1 − u ≥ η/2.

Then Δh_j = h_uΔu_j + h_βΔβ_j + h_γΔγ_j + O(|Δ|²), and:
- Δ²h_j = O(|Δ²u_j| + |Δu_j|·|Δ(u, β, γ)| + |Δβ| + |Δγ|) = O(j^{−1−ε});
- Δ²u_j = Δu_{j−1}γ_{j−1} + u_{j−2}Δγ_{j−1} = O(j^{−1−ε}).

So Δ²log σ_j = O(j^{−1−ε}) uniformly in u_j ∈ (0, 1 − η/2]. This gives ΔD_j = O(j^{−1−ε}): D_j = e^{Δlog σ_j} − 1 = Δlog σ_j + O(j⁻²),
and Δ of an O(j⁻²) sequence is O(j⁻²).

Next, the derivative itself. ∂_u log S(u, 0, 0) = 1/u + 1/(s(1 + s)) with s = √(1 − u), and this equals 1/(u√(1 − u)). I
re-derived the identity using 1 − u/2 + s = (1 + s)²/2.

Hence Δlog σ_j = (1 + uh_u(u, 0, 0))·Δlog u_j + O(j^{−1−ε}) = −p/(j√(1 − u_j)) + O(j^{−1−ε}). The β, γ dependence of h_u
contributes O(1/j)·Δu_j = O(u/j²).

The remaining claims of (c) check out:
- θ_j − θ̄_j = O(Φ″σ_j|e_j|) with Φ″ ≍ u³, so this is O(e_j);
- E_j = D_j/(1 − θ̄_j) with θ̄_j = (1 + γ_j)σ_j³/σ_{j−1}. This uses Φ_j′(σ_j) = b_{j+1}σ_j²/b_j, from d(σ_j) = b_j/σ_j;
- ΔE_j = ΔD_j/(1 − θ̄) + O(j⁻²) = O(j^{−1−ε});
- the ẽ recursion: ẽ_{j−1} = θ_jẽ_j + E_j(θ_j − θ̄_j) + ΔE_j. The middle term is O(|E_j||e_j|) = O(j⁻²); the file writes |e_j|²,
  which is the same order.

Conclusion (c): log ρ̂_j − log ρ̂_{j−1} = −p/(j√(1 − u_j)) + O(j^{−1−ε}), uniformly. **Correct.** As a by-product,
Δ²log ρ̂_j = O(j^{−1−ε}): the main term has differences O(j⁻²), since Δu_j = O(u_j/j).

### 2.4 Step (d): the missing argument (F1, MINOR)

The file says: "log G_m = g(u_m) + O(m^{−ε}) with g smooth, and its first differences are O(1/m) with second differences
O(m^{−1−ε})". The first clause does not imply the third, and no argument is given beyond "the same contraction argument
applies". The claim is true. Here is a complete argument, using only (c).

Put Ḡ_m := 1/(1 − ρ̂_m²), the fixed point of G ↦ 1 + ρ̂_m²G, and f_m := G_m − Ḡ_m. From G_m = 1 + ρ̂_m²G_{m+1}:

  f_m = ρ̂_m²f_{m+1} + ρ̂_m²(Ḡ_{m+1} − Ḡ_m),  so  f_m = Σ_{i≥0}π_{m,i}ΔḠ_{m+i+1},  π_{m,i} := Π_{l=0}^{i}ρ̂_{m+l}² ≤ q^{i+1}.

Here ΔḠ_k := Ḡ_k − Ḡ_{k−1}. Since log Ḡ = −log(1 − e^{2log ρ̂}) is a smooth function of log ρ̂ on ρ̂² ≤ q:
- ΔḠ = O(|Δlog ρ̂|) = O(1/m);
- Δ²Ḡ = O(|Δ²log ρ̂| + |Δlog ρ̂|²) = O(m^{−1−ε}), by the by-product of (c).

Then

  f_m − f_{m−1} = Σ_i(π_{m,i} − π_{m−1,i})ΔḠ_{m+i+1} + Σ_iπ_{m−1,i}Δ²Ḡ_{m+i+1}.

Two estimates finish it:
- π_{m,i}/π_{m−1,i} = ρ̂²_{m+i}/ρ̂²_{m−1} = exp(2Σ_{l=m}^{m+i}Δlog ρ̂_l) = 1 + O((i + 1)/m)·e^{C(i+1)/m}. Against q^{i+1} this sums
  (for m ≥ n₀ with qe^{C/n₀} < 1) to O(1/m), so the first sum is O(m⁻²).
- The second sum is O(m^{−1−ε}).

Hence Δf = O(m^{−1−ε}), and f = O(1/m).

Finally, log G = log Ḡ + log(1 + f/Ḡ), with Ḡ ≥ 1:
- Δ²log Ḡ = O(m^{−1−ε});
- Δlog(1 + f/Ḡ) = O(|Δf| + |f||ΔḠ|) = O(m^{−1−ε}), so its second difference is O(m^{−1−ε}) as well (it is at most twice the
  sup of the first).

So Δ²log G_m = O(m^{−1−ε}), uniformly in u. All terms carry a factor ρ̂² ≲ u², so the bound improves as u → 0.

T2 confirms that this term is in fact O(n⁻²)·(a function of u), well below the claim. The clause "log G_m = g(u_m) + O(m^{−ε})"
is true (with O(1/m)) but unused, and should be dropped.

The identity F(m+1) − F(m) = −2log ρ̂_m − log(G_{m+1}/G_m) and the resulting second difference are correct. I re-derived them
from T_m = P_m(x₀)²G_m.

## 3. Lemma H (§3.1)

The algebra checks out. Write q = e^{−2πit₊}, with |q| < 1 for p > 1. Then 𝔢_δ = 2Im Log(1 − qe^{2πiδ}) = −2Im Σ_mq^me^{2πimδ}/m.

∫_0^∞q^mr^{−k−1}dr = pΓ(kp)(2πmn)^{−kp}(−1)^ke^{−iπkp/2}, so

  ∫_0^∞𝔢_δ(−r)r^{−k−1}dr = −2(−1)^kpΓ(kp)(2πn)^{−kp}Σ_m sin(2πmδ − πkp/2)/m^{1+kp} = 2(−1)^kpΓ(kp)(2πn)^{−kp}S,

The formula relied on (Hurwitz) is

  ζ(1 − σ, a) = 2Γ(σ)(2π)^{−σ}Σ_{m≥1}cos(πσ/2 − 2πma)/m^σ,  0 < a ≤ 1, Re σ > 1.

since Re σ > 1). So m_k = ζ(−kp, a)/(kn^{kp}). **Correct.**
